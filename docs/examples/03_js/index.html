03_JavaScript_기초.docx 예제

각 장마다 HTML 페이지 하나와 JS 파일 하나가 짝을 이룹니다. 모든 페이지에 실행 결과 영역이 있어 개발자 도구를 열지 않아도 결과를 볼 수 있지만, F12 → Console 을 함께 열어두는 것을 권합니다.

알아두기 11장(fetch)은 반드시 Live Server 로 열어야 합니다. 파일을 더블클릭해 열면 file:/// 주소가 되어 fetch 가 차단됩니다.
  • 1장JavaScript 붙이기와 콘솔 — script 위치, console.log / error / table
  • 2장변수 — const 와 let — 재할당, const 객체의 속성 변경
  • 3장자료형과 템플릿 리터럴 — typeof, trim, 백틱과 ${ }
  • 4장연산자 — === vs ==, truthy/falsy, 삼항과 ||
  • 5장조건문과 반복문 — 모드 분기, early return, forEach/for-of/for
  • 6장함수와 화살표 함수 — 괄호의 차이, => 생략 규칙, 콜백
  • 7장객체 — 평평한 구조 vs detailRequest 중첩, JSON
  • 8장배열과 배열 메서드 — forEach, map/filter/find, 표 그리기와 중복
  • 9장DOM — 화면과 대화하기 — 요소 찾기, value, textContent vs innerHTML
  • 10장이벤트 — preventDefault 비교, click/input/change
  • 11장비동기와 fetch — 실행 순서, then 체인, response.ok 함정, POST
  • 12장오류 메시지 읽는 법 — 대표 오류 6종을 직접 발생시켜 보기
