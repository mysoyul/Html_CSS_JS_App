02_CSS_기초.docx 예제

각 장마다 HTML 페이지 하나와 CSS 파일 하나가 짝을 이룹니다. css/ 폴더의 CSS 를 직접 고쳐 보면서 화면이 어떻게 바뀌는지 확인하세요.

  • 1장CSS 를 붙이는 세 가지 방법 — 인라인 · 내부 · 외부
  • 2장선택자와 우선순위 — 점과 샵, 공백의 의미, 취소선 읽기
  • 3장박스 모델 — 네 겹 구조, box-sizing 비교, margin auto
  • 4장display — block · inline · inline-block · none
  • 5장Flexbox — justify-content 6가지, align-items, 정중앙 배치
  • 6장CSS Grid — fr, repeat, auto-fit + minmax
  • 7장단위와 색 — px/%/rem/em/vw/vh, hex와 rgba
  • 8장글꼴과 텍스트 — line-height, 시각적 위계
  • 9장배경 · 테두리 · 그림자 — border-radius, box-shadow, overflow
  • 10장position — relative/absolute 한 쌍, sticky
  • 11장transition 과 hover — 평소 상태에 쓰는 이유, 카드 떠오르기
  • 12장반응형과 미디어 쿼리 — viewport, @media, auto-fit 비교
